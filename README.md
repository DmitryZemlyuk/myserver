# My Server

Private server monitoring dashboard: service health, uptime history, resources,
WireGuard peers and traffic, in Ukrainian, Russian and English.

`lampa/sync.js` – a Lampa plugin: bookmarks, watch marks, profiles and settings backups synced through the server,
plus new-episode notifications.

`notes/` – a private notes site (installable PWA, works offline and syncs with the server):
folders, tags, formatted text, checklists, pictures and files, search.
